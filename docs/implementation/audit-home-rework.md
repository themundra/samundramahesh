# Audit — Home page rework

## Pattern from services / portfolio
- Strong page framing (eyebrow + headline + support)
- Exploration strip where useful (not in hero)
- Compact rows linking to detail pages
- Closing CTA section
- One job per section; Ink Studio hairlines, no marketing card stacks in hero

## Home gaps
| Section | Issue |
| --- | --- |
| Hero | OK brand-first; copy can align with broader services lineup |
| Selected work | Rows OK; missing compact scan / “featured first” framing parity |
| Services | List OK; could use mini scan or clearer Explore language |
| Experience | Accordion OK; framing can match editorial tone |
| Blog | Thin teaser |
| Contact CTA | Generic |

## Decision
1. Keep hero one-composition (no service tiles in hero).
2. Add home content module for section copy.
3. Selected work: short intro + portfolio-style rows (already) + optional 3-up scan for featured only.
4. Services: keep list → detail; tighten copy.
5. Experience / blog / contact: richer support lines; blog rows closer to portfolio row language.
6. Align hero with live “Hi — I'm Samundra” spirit without cluttering first viewport.
